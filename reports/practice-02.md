Источник данных:
- `data/raw/masterpieces.json`
- формат: JSON
- количество записей: 97

Из JSON для каждого объекта формируется поисковый текст с полями: название, инвентарный номер, тип, страна, период, год создания, материал, размер, авторы, описание и другие доступные сведения.

Очистка текста выполняется детерминированно: декодируются HTML-сущности, удаляются лишние пробелы и технические переносы.

## Словарь рубрик

Для метаданных `category` используются четыре рубрики:

| Рубрика | Правило |
| --- | --- |
| `object` | название, тип, страна, описание, аннотация, размер |
| `period` | период, дата/год создания, эпоха, династия, век |
| `attribution` | автор, авторы, материал, техника, место создания |
| `collection` | инвентарный номер, коллекционер, происхождение, год поступления |

Если ни одно правило не срабатывает, используется рубрика `object`.

## Замеры

Проведены два запуска с различными параметрами фиксированного чанкинга.

| № | CHUNK_SIZE | CHUNK_OVERLAP | Чанков в индексе | hit-rate@5 | hit-rate@1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 | 512 | 64 | 230 | 100% (10/10) | 100% (10/10) |
| 2 | 384 | 48 | 283 | 100% (10/10) | 100% (10/10) |

Во всех экспериментах использовался один и тот же набор из 10 вопросов `gold_dataset.json`.

## Выбранная конфигурация

Для дальнейшей работы выбрана конфигурация:
- `CHUNK_SIZE = 512`
- `CHUNK_OVERLAP = 64`

Обе конфигурации показали одинаковые значения hit-rate@1 и hit-rate@5. При этом конфигурация 512/64 формирует меньше чанков: 230 против 283.

Таким образом, при одинаковых измеренных значениях retrieval-метрик вариант 512/64 позволяет использовать более компактный индекс.

Важно учитывать ограничение текущего эксперимента: весь корпус представлен одним исходным файлом `masterpieces.json`. Поэтому проверка `expected_sources` оценивает попадание в правильный файл-источник, а не точность определения конкретного музейного объекта. Поэтому одинаковые значения hit-rate не следует интерпретировать как доказательство полного совпадения ответа с нужным объектом.
